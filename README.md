# Інформатика 10 клас (поглиблений рівень) — Уроки 11–12 та ПР №3

Інтерактивний навчальний веб-додаток за програмою **М. Ю. Арбузова, І. О. Забзанової** (Розділ 3 «Циклічна алгоритмічна структура», мова програмування C++).

## Теми уроків у комплекті
- **Урок 11:** Цикл `for`. Складні відсотки. Факторіал. Числа Фібоначчі.
- **Урок 12:** Вкладені цикли. Геометричні фігури. Гіпотеза Коллатца (**Практична робота №3**).

## Вміст архіву
- `index.html` — повністю автономна інтерактивна веб-сторінка (теорія, симулятори трасування, генератор фігур, графік Коллатца, тренажер із оцінюванням, інструкція з GitHub Pages та кабінет вчителя).
- `README.md` — опис репозиторію для швидкого розгортання на GitHub.

## Як опублікувати веб-сторінку на GitHub Pages
1. Розпакуйте архів та завантажте файли `index.html` і `README.md` у свій публічний репозиторій на GitHub.
2. Відкрийте **Settings → Pages** у репозиторії.
3. У розділі **Branch** оберіть `main` та папку `/ (root)`, натисніть **Save**.
4. Через 1–2 хвилини веб-сторінка стане доступною за адресою `https://<ваш-логін>.github.io/<назва-репозиторію>/`.
